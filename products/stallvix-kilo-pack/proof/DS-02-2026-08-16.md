## Reusable lesson found

A permission key named `edit` is not a file-modification group. Kilo documents `write` and `apply_patch` as separate tools. If the public docs do not prove inheritance, duplicate the deny map and refuse to score runtime PASS. Same pattern as `read` ≠ `grep`.
